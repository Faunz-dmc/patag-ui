# PATAG LGU portal

Independent React / TypeScript / Vite application. See the repository-root README for the local API and three-app workflow.

```powershell
npm install
npm run dev
npm run build
```

Default port: 5173. API: http://127.0.0.1:4100/api. Copy `.env.example` to `.env.local` only to override. Use the demo-role button on the login page; seeded accounts do not have made-up passwords. All data is fictional.
